# オツカレ∞キャンディ 公式サイト

「オツカレ∞キャンディ」の公式サイトプロジェクトです。
ポップでキュートなデザインで、疲れた心に癒やしを届けます。🍬

## 📂 プロジェクトの再開方法

### 1. 準備（同じPCで作業する場合）
プロジェクトフォルダ `c:\Users\user\Desktop\オツカレキャンディサイト` を VS Code などのエディタで開いてください。

### 2. プレビュー方法
- **index.html** を直接ブラウザ（Chromeなど）にドラッグ＆ドロップするか、ダブルクリックして開くだけで見ることができます。
- VS Code の「Live Server」拡張機能などを使うと、編集がリアルタイムに反映されて便利です。

### 3. 別のPCで作業する場合
GitHubからリポジトリをダウンロード（クローン）してください。
```bash
git clone https://github.com/kazuyatahara/otsukarecandy.git
```

## 🛠️ 編集と保存（GitHubへのアップロード）

変更を加えたら、以下のコマンドで保存・アップロードできます。

```bash
# 1. 変更をステージング
git add .

# 2. 変更内容を記録（"変更のメモ"をわかりやすく！）
git commit -m "ここに変更内容を書く"

# 3. GitHubへアップロード
git push
```

## ✨ 主な機能
- **ヒーローセクション**: 虹色のポップなロゴと、大きな集合ビジュアル
- **メンバー紹介**: くるっと回るフリップカード（裏面はテーマカラー）
- **癒やしボタン**: 右下の飴玉ボタンを押すと、ランダムでメンバーが励ましてくれます
- **装飾**: なみなみの境界線、揺れるパーティクル、ぷにぷにアニメーション

## 📁 重要なファイル
- `index.html`: ページの構造
- `style.css`: デザイン（色、フォント、アニメーション）
- `main.js`: メンバーデータや動きの制御
- `hero-visual.png`: トップページの集合画像
